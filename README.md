# Горизонт 45

Официальный сайт концепции ландшафтного комплекса у Бухты Космонавтов на Керченском полуострове.

Рабочая версия: [gorizont-45.semenovspb.chatgpt.site](https://gorizont-45.semenovspb.chatgpt.site)

## Что входит в проект

- адаптивный одностраничный сайт на русском языке;
- описание концепции, архитектуры, пространств и общественной программы;
- полноэкранные и мобильные композиции;
- встроенный панорамный 3D-тур проекта «Азгард»;
- изображения территории и архитектурных концептов;
- автоматические проверки сборки и интерфейса.

## Технологии

- React 19;
- Next.js 16;
- Vinext и Vite;
- TypeScript;
- Tailwind CSS;
- Cloudflare Workers.

## Локальный запуск

Требуется Node.js версии `22.13.0` или новее.

```bash
npm ci
npm run dev
```

Проверка перед публикацией:

```bash
npm test
npm run lint
```

## Основные файлы

- `app/page.tsx` — структура и содержание главной страницы;
- `app/globals.css` — визуальная система и адаптивные стили;
- `public/images/` — изображения проекта;
- `tests/` — проверки сборки и компонентов;
- `.openai/hosting.json` — привязка к существующей публикации сайта.

## 3D-тур

Панорамный обзор встроен с сайта [azgard-crimea.ru](https://azgard-crimea.ru/). На странице также предусмотрена ссылка для открытия тура на весь экран.

## Работа с изменениями

Разработку следует вести отдельными ветками. Перед объединением изменений в `main` необходимо проверить мобильную и широкоформатную версии, корректность изображений и работу 3D-тура.
